# Changelog

Each version of the ASCDII Engine extension, newest first. The section of a
version becomes the notes of its release, and a version is published only
when it has a section here.

## 0.1.0

- An Explorer view of an ASCDII project's assets by kind, with the objects
  that use each script, the start scene marked and `.meta` files hidden.
- Lua with the engine's API in completion and on hover, the hooks as
  snippets, the script's fields after `self.`, and syntax errors as you type.
- Play in the game's window or the ASCDII editor, picked beside Play, Stop
  and Build, with the game's output in Output and script errors in Problems.
  Needs BMEditor 0.1.5.
